# Fala para Texto: Transcritor PT-BR

Aplicativo gratuito para transcrever fala em português brasileiro diretamente no navegador. O visual segue a categoria **Fintech & Apps**, com fontes Plus Jakarta Sans e DM Sans e a paleta #E76F51, #F4A261, #E9C46A, #2A9D8F, #264653 e #F8F9FA.

## Como usar

1. Abra `index.html` no Google Chrome atualizado.
2. Permita o acesso ao microfone e selecione **Começar a gravar**.
3. Selecione **Parar e copiar** para finalizar e copiar o texto. Use os demais botões para continuar, limpar, copiar ou salvar a transcrição como arquivo `.txt`.
4. Você também pode editar o texto transcrito diretamente na área de texto.

O reconhecimento de fala depende do suporte do navegador e pode exigir conexão com a internet. O aplicativo não precisa de instalação nem de etapas de build.
